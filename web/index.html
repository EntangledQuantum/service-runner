Service Runner is the local production host for long-running web apps. Register a project once. It survives reboot. Agents restart it through an API instead of babysitting pnpm dev in another PowerShell window.

Open dashboard Install

Running on this machine at

This page is the public site. The dashboard and process supervisor only run on your Windows PC.

Tray

One icon, every process

Left-click opens this site. Right-click starts or stops groups, restarts a service, or quits — and quitting stops the children too.

Agents

A prompt they can paste

The dashboard exposes a two-line prompt with this machine’s URL, token, and log path. PUT a stable id to register. POST restart after a code change.

Local only

This PC, never a remote

The API binds to 127.0.0.1. Project folders must be absolute local drives. URLs, git remotes, and network shares are rejected.

Install

git clone https://github.com/EntangledQuantum/service-runner.git
cd service-runner
pnpm install
pnpm start

Windows. Node 22+. After pnpm start the terminal hands off to the tray — close the window. It also adds a logon shortcut. Config: %LOCALAPPDATA%\ServiceRunner (not in git).

Uninstall

  1. Right-click the tray icon → Quit Service Runner (stops every child).
  2. From the clone: pnpm run uninstall:startup — removes the Windows logon shortcut.
  3. Optional: delete %LOCALAPPDATA%\ServiceRunner and the cloned folder.
